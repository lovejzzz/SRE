## 1. 目标与体验标准

让用户按「选地 → 建房 → 装修 → 布置 → 走进去 → 保存作品」完成一栋真实可用的住宅。覆盖住宅、小院、车库、地下室、二楼及更高楼层；不牺牲现有素材、车辆、物品库存、旧住宅和本地存档。界面保持英文、深绿/暖灰/黄铜配色；视觉升级为可旋转观察、有真实体积和统一光照的微缩建筑风格。以《模拟人生4》的易用性为品质参照，不将第一阶段描述为同等完成度。

核心标准：指向可见对象就能操作它；预览即结果；一次意图对应一次撤销；房子能住且可恢复；高级能力渐进呈现。视觉标签优先，但对象名称、错误原因、确认中的变更不能省略。

## 2. 初始基线与问题（2026-10-12，后续进展见执行记录）

已有：房间矩形绘制、单物件放置/移动/复制、门洞材质组合、楼层切换、楼梯组合、车辆与库存、撤销重做、场景预览、本地草稿、房屋库、新建前归档、导入导出、触控板平移/缩放、放置尘土和音效。

缺口：鼠标先投影到地面格，点可见墙面会误放到后方；房间缺少可编辑边界；同一物件各朝向及原始碎片挤满目录；无法成组编辑；可达性主要靠试走；草稿和入住住宅没有清晰身份/版本关系。全量分类审计不等于逐张艺术资产或每种建筑组合已验收。

## 3. 信息架构

- 顶栏：House library、房名、保存状态、Save、Walk through、Return。
- 左栏：Search；按房间/用途浏览；对象类别；必要时展开筛选。不得同时出现两套常驻密集标签。
- 工具栏：Select、Build、Furnish、Landscape；在各模式内呈现相关工具。进入新模式不修改文档。
- 画布：选中轮廓、吸附面、占地、旋转/缩放手柄、楼层与视图；不常驻长教程。
- 底部上下文条：只显示当前对象、变体、材质、复制/删除等相关操作。
- Help：快捷键和手势；所有纯图标具有英文 tooltip、可访问名称和键盘焦点。

保留现有工具到对应新位置，分阶段迁移；不先删功能再补回来。

## 4. 工作流 A：准确放置与智能吸附（P0）

### 行为

1. 从目录拿起对象，指针进入画布后显示半透明实体与支持面轮廓。
2. 门、窗识别可见墙面；墙面装饰识别实体墙；窗帘识别窗；桌面用品识别桌台表面；车辆识别完整停车占地。
3. 命中按当前楼层及绘制深度选择最前方可见支持面，不穿过前墙选后墙，不吸到楼下。用户明确开启 cutaway 时仍有边缘提示。
4. 有可靠同款变体时随墙方向选 N/W；不拿另一款门冒充旋转。无变体时红色轮廓提示 Rotate to match this wall。
5. 有效轮廓绿色，无效红色并给简短具体原因；没有支持面时不允许静默落到地面格。
6. 一次点击放置；门窗不因手抖拖动连续打洞。连续墙面铺贴是单独明确的工具。
7. 门窗保留匹配墙体门洞/窗洞；宽窗检查每一段墙。替换不会删除其他方向墙或无关对象。
8. Esc、失焦、取消指针操作恢复原件；撤销恢复材质、位置、库存与依附物。

### 反馈

吸附面边线和实际落点同步。成功后 100–180ms 轻微落下回弹，短促低音和局部尘土；无效放置不播放成功反馈。减少动态效果模式禁用震屏、保留选中反馈；声音服从总音量。

### 验收

在两个墙方向、三个缩放级别、移动过镜头、Ground/B1/F2 中，点击墙中部放门；预览与导出坐标一致、没有地面误放。验证角落、前后墙重叠、没有墙、缺少方向变体、双格窗一半无支撑、撤销重做、取消移动。进游戏完成开门/通行。桌台/窗帘/挂画分别有独立支持面测试。

## 5. 工作流 B：以房间为单位建造（P0，依赖 A 的边界模型）

### 行为

- 拖出房间显示宽深、占地和边界；释放前不持久修改。
- 选房间后拖边扩缩、拖角调整；共享墙只保存一次，合并房间可移除内部墙。
- 选整面墙更换材质，保留门窗、墙角和挂件；区分单段/连续墙/整屋应用范围。
- 移动边界遇到家具、楼梯、地界或相邻楼层连接时预览冲突，明确拒绝或让用户选择搬移；不得静默删除。
- 楼层用剖面缩略图呈现。加二楼/地下室时创建支持楼板；楼梯预览包括上下平台、洞口和净空。删除楼梯前显示将失联的区域。
- 屋顶有适配占地的成组预览，独立控制显示，不把它伪装成普通地板。

### 数据与验收

引入 derived room graph（由边界与地板推导）后再持久化可编辑 room IDs；旧图块存档可导入但不强行识别成准确房间。整屋调整是原子命令。验收矩形/L形、两间共享墙、门窗墙材替换、带家具缩房、地下室与二楼连续通行、撤销完整恢复。

## 6. 工作流 C：可浏览的素材库（P1，可与 B 分别推进）

- 房间入口：Living、Bedroom、Kitchen、Bathroom、Garage、Shelter、Garden；对象可属于多个用途。
- 物件类别仍保留；按材质、色系、风格、尺寸、支持面筛选。未知标签不猜测为事实，允许未标注。
- 一张卡代表一件完整物件；朝向、色款在卡片/上下文中切换；开启、破碎等状态通常属于对象状态，不作普通推荐卡。
- 原始墙片/屋顶片、状态贴图、无可靠组合定义的零件收在 Advanced tiles，仍可搜索和放置，不删除素材。
- 卡片缩略图统一背景与构图，宽物件显示占地；悬停才给长名称，必要时显示多部件标记。
- Recent、Favorites 与搜索相关性优先于资产文件名；搜索稳定保留用户刚选择的分类。
- 数据结构：asset family、variants、footprint、mount、semantic tags、source provenance、confidence。只合并有可靠证据的变体。

验收：用普通英文找到钢琴、白色沙发、浴室洗手台、双格落地窗、地下室货架；同物件不铺满列表；原始图块仍可取回；全量分类/家族审计加代表性视觉抽查；车辆异步载入不阻塞建造。

## 7. 工作流 D：高效编辑（P1）

- 点击选中后再移动，不在第一次选中时立即拿走原件；选中轮廓准确覆盖物件。
- Shift 追加选择；框选可见对象；多层对象有可视层选择；锁定对象不参与误选。
- 支持组移动、复制、旋转、删除；对象与桌面摆件、柜内库存默认一起移动。跨楼层操作检查支持面。
- 材质吸管只取材质，物件复制取完整组合；拖动尺寸手柄不得改变不支持缩放的像素资产比例。
- Cmd-Z / Shift-Cmd-Z；命令有清晰名称；组合操作只需一次撤销。

验收：床+两床头柜+灯整体移动、柜内库存不丢、撞墙时整组拒绝、Esc还原、锁定地板不误删、撤销/重做/保存重载后完整一致。

## 8. 工作流 E：可居住性检查（P1 基础，P2 深度）

- 放置时局部检查门摆动/通行、物件使用站位、楼梯平台、楼层支持；只显示涉及当前操作的问题。
- Walk through 前提供可折叠检查摘要，点击问题定位并高亮。明确区分错误、建议和尚无法验证。
- 从入口做角色足迹尺寸的连通性检查；床、储物、电脑、厨房设施与卫生设备标记可到达站位。
- 所谓「可使用」必须连接真实游戏动作，不以物件存在或一条中心线路径替代交互验证。
- Shelter 的一年生活能力属于独立供水/空气/供电/废物/消耗模拟验收，不由房屋布局扫描给出保证。

验收：故意堵门、封楼梯、床夹墙、地板洞、地下室失联；定位正确、修正后消失；窄过道实际角色试走；保存和导出不因建议项被禁止。

## 9. 工作流 F：作品与版本库（P1）

- 分离 Stable house ID、Draft、Saved revision、Active residence；当前入住和编辑中显示不同视觉标签。
- New house、Duplicate、Rename、Save revision、Restore version、Export/Import 在 House Library 内。
- 卡片显示房屋实景、名称、层数、最近保存时间；地下室能切换预览，旧住宅保留。
- 自动草稿不等同于创建人工保存版本。恢复旧版先保留当前稿；删除可进回收区，不能只靠浏览器确认弹窗。
- IndexedDB 适配大库/预览，保留 JSON 导出；迁移验证成功之前不删 localStorage 旧副本。
- 多标签页发现版本冲突时保留两个分支，不最后写入者覆盖；容量满或导入损坏必须可恢复。

验收：新建前保留、复制互不影响、恢复再撤销、断网、刷新、容量失败、旧格式导入、两标签编辑冲突、误删恢复。浏览器本地存档仍是默认，不要求账户/服务器。

## 10. 技术拆分与迁移

保留现有 WorkshopModel、Renderer 与 plan v1 的兼容性，逐步抽出：

- placement resolver：屏幕命中 → 支持面 → 方向变体 → 预览/提交共用 placement intent。
- asset manifest：语义家族、用途、尺寸、安装约束；源属性修正可追溯。
- building topology：wall edges、openings、room graph、floor links；不把渲染贴图当唯一拓扑。
- command layer：原子提交、撤销与依附关系；拖动为 transient preview。
- validator：局部支持/占地检查与异步全屋可达性检查。
- library storage：稳定ID、版本、草稿与入住引用；迁移有原始备份。

避免继续向 workshop.js 加所有逻辑。新功能使用专用纯函数模块与适当集成测试。持久格式变化通过 version + 显式迁移，不覆写用户原档。

## 11. 性能、可访问性与错误处理

验收设备以用户 MacBook 触控板浏览器为目标；IAB 合成输入不能冒充硬件测量。连续拖动目标为60fps，至少记录帧耗时/长帧；输入解析目标在16ms帧预算内，失败则建立空间索引与缓存。目录只渲染可见区域及少量预加载行，缩略图缓存有界。目标值不写成已测结果。

测试默认1280宽、960宽与窄屏回退；键盘可到达工具、图标有名称、焦点明确。画布操作提供必要状态朗读而非每帧播报。加载失败保留操作、显示重试；退出前保存失败明确可见。
