## 1. Momento Brewers Café — 第一例，紧凑商业空间

开发输入与验收要求已另行冻结：[Momento development case v1](MOMENTO-DEVELOPMENT-CASE.md)。当前已完成四图导入、14处标注与第一版可编辑外壳/吧台；材料、内饰与照片保真仍未通过验收（190）。

- [项目照片与平面图](https://www.archdaily.com/983949/momento-brewers-cafe-studio-hoon)。来源标注47平方米，包含吧台空间、另一处开放空间及连接内外的窗台。
- [代表照片](https://images.adsttc.com/media/images/62b0/6fca/45e0/bb44/b12e/53a7/large_jpg/momento-brewers-cafe-studio-hoon_1.jpg?1655730186)。
- [另一个照片视角](https://www.archdaily.com/983949/momento-brewers-cafe-studio-hoon/62b06fd145e0bb44b12e53ab-momento-brewers-cafe-studio-hoon-photo)。
- 建议输入：外部照片、吧台内部照片、反向室内照片；平面图单独作为核对资料，另做提供平面图的辅助任务，不混淆输入条件。
- 先验证：墙/开口、窗台与吧台组合、设备和桌面物品安装、狭小空间通路、材质分配。
- 完成检查：入口到吧台、窗口前的可用站位；窗洞保留墙体；吧台及设备可独立编辑；保存重开一致。
- 选择理由：范围比整栋住宅小，但有明确的空间用途和室内外联系，适合作为第一个完整闭环。

## 3. Warehouse Morinha — 第三例，仓库改造的陈列空间

- 设计：stu.dere。
- [项目来源](https://www.archdaily.com/949324/warehouse-morinha-stere)。
- [代表照片](https://images.adsttc.com/media/images/5f82/57e1/63c0/1748/5c00/00e2/large_jpg/3.jpg?1602377660)。
- [补充报道与照片](https://worldarchitecture.org/architecture-news/egegn/stu-dere-divides-interior-space-with-golden-wire-meshes-for-multiple-uses-in-this-store-in-portugal.html)。报道说明其仓库改造、网状隔断及楼上摄影工作室。
- 建议输入：内部全景、隔断近景、上层与楼梯关系；正式任务再固定可核对的图纸与尺寸。
- 先验证：大跨度空间表达、透明隔断、重复陈列台、成组复制与对齐、上下层动线。
- 完成检查：隔断具备正确的通行边界；陈列组可整体编辑；大空间不因重复对象造成明显操作卡顿。
- 选择理由：用于验证商业/工业空间，不沿用住宅房间模板。它是仓库改造后的展示空间，不能用作货架物流仓库功能已完成的证明。

## 建议顺序与输入管理

先做咖啡馆，再做庭院住宅，最后做仓库改造。每组采用两种独立任务条件：照片-only（图纸留作核对）、照片+图纸（辅助空间还原）。预先固定照片数量、是否提供尺寸和允许的近似，不在任务中途偷偷扩大输入。

这些例子现已用于开发规划，不能再被称为“模型从未见过的最终盲测”。学校、商住楼和另一组住宅的最终验收照片，在工坊能力和版本冻结后另选。
